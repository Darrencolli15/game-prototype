# Bramble Brigade

A free browser playtest of the Bramble Brigade strategy game.

## Publish with GitHub Pages

1. Extract this folder's contents. Upload the contents directly to the top level of your public repository, where `index.html` will appear.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**, choose **main** and **/(root)**, then save.
4. Open the website link GitHub shows in the Pages section.

The game runs in a browser and saves progress on that device. Premium checkout is only available in the iOS app.
